# ميزانية الأب الغني

تطبيق ويب بالعربية يطبّق أفكار كتاب «الأب الغني والأب الفقير»:
- الدخل النشط والدخل السلبي
- الأصول والالتزامات وصافي الثروة
- التدفق النقدي الشهري
- مؤشر الخروج من «سباق الفئران»
- خطة «ادفع لنفسك أولاً» وحساب الأصول المطلوبة للحرية المالية
- تصدير واستيراد نسخة احتياطية

البيانات تُحفظ على جهاز المستخدم فقط (localStorage) ولا تُرسل لأي خادم.
يمكن تثبيته على أندرويد كتطبيق (PWA) ويعمل بدون إنترنت.
